# Raya

Research runtime: Rust CPU inference for Laya-style encoder-only decision models (Laya shape, fp32,
inference only). Scope, measurements and open questions: [docs/feasibility.md](docs/feasibility.md).
Work is specified in [specs/](specs/README.md) (Spec Kit; rules in `.specify/memory/constitution.md`). Nothing is implemented yet.

`reference/laya-sparse/` is a read-only git submodule of the Python research repo. After cloning:
`git submodule update --init`.
