`/speckit-plan`, `/speckit-tasks`, `/speckit-implement`, one branch and one PR per feature, merging a
feature before starting its dependents. Governing rules: `.specify/memory/constitution.md`; scope:
`docs/feasibility.md`.

laya-sparse; their output is vendored into raya.

## Bridging the two repos

- laya-sparse is the read-only submodule `reference/laya-sparse/`. Run `git submodule update --init`
  first; if it is empty, stop. To move to newer Laya: push in laya-sparse, then
  `git submodule update --remote reference/laya-sparse` in raya and commit the pointer.
- Never edit `reference/`. Fixtures generated by 002 and 004 are copied into `tests/data/` with the
  laya-sparse SHA in each `meta.json`, and re-generated (never hand-edited) when Laya changes.
- Note: Laya's `experiments/` directory is at the laya-sparse root, not under `laya/`.
